05 / Project

PagedServe

High-throughput LLM inference server

Python · PyTorch · C++17 / pybind11
CUDA · FastAPI

View on GitHub ↗ Interactive demo ↗

The core mechanisms of modern LLM serving, from scratch.

Paged memory for the KV cache, a scheduler that works per decode step, and prefix sharing, with a benchmark harness to keep the numbers honest.

3.4×more concurrent sequences in the same GPU memory
6.8×throughput over HuggingFace generate() at 32 concurrent
61%lower P99 TTFT on shared-prefix traffic
  • Paged KV cache: a fixed-size block allocator with per-sequence block tables replacing contiguous max-length pre-allocation, fitting 3.4× more concurrent sequences in the same GPU memory.
  • Continuous batching with a per-decode-step scheduler that admits, preempts, and retires requests mid-flight: 6.8× throughput over HuggingFace generate() at 32 concurrent requests.
  • Block-aligned prefix caching with refcounted shared blocks: P99 time-to-first-token down 61% on shared-prefix traffic.
  • C++17/pybind11 bindings, a FastAPI serving layer, and a reproducible benchmark harness: 1–64 concurrency sweep, medians over 3 warmed runs, matched GPU, model, and sampling.

GRPO from scratch, verified on GSM8K.

Group Relative Policy Optimization implemented by hand to post-train a small open model on grade-school math with a verifiable reward.
